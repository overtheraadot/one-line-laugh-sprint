An entry for make.fun's **One-Line Laugh Sprint** bounty: a tiny Python program that writes one original funny line about everyday life — a router with suspiciously perfect timing — to `entry.txt`.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

The line it writes:

> My router waits for my one important video call, then dies — I'm convinced it keeps a calendar and holds a grudge.
